# SwayFX (HyDE-ARM64) — Keybindings

`⌘` = Super (Mod4), `⌥` = Alt (Mod1)

## Terminal
- `⌘+Return` — kitty
- `⌘+Shift+Return` — kitty (floating)
- `⌘+⌥+Return` — kitty (small)
- `⌘+T` — kitty (fullscreen)

## Apps
- `⌘+N` — file manager (thunar)
- `⌘+Shift+E` — editor (geany)
- `⌘+Shift+W` — browser (brave)

## Launchers (rofi / wofi)
- `⌘+Space` / `⌘+D` — App launcher (Spotlight)
- `⌘+R` — Run command
- `⌘+Shift+U` — Music menu (mpc)
- `⌘+Shift+N` — Network menu
- `⌘+X` — Power menu
- `⌘+A` — Screenshot menu
- `⌘+E` — Emoji picker
- `⌘+P` — Color picker (grim+slurp)

## Window management — macOS style
- `⌘+W` / `⌘+Q` — close window
- `⌘+F` — fullscreen toggle
- `⌘+Shift+F` — floating toggle
- `⌘+Ctrl+Space` — float + center
- `⌘+H` / `⌘+M` — hide to scratchpad
- `⌘+Shift+H` / `⌘+`` ` `` — unhide last scratchpad
- `⌘+Shift+P` — pin (sticky)
- `Ctrl+⌥+Delete` — exit sway

## Focus / Move / Resize
- `⌘+←↑↓→` — focus direction
- `⌘+Shift+←↑↓→` — move window
- `⌘+Ctrl+←↑↓→` — resize (±20px)
- `⌘+⌥+←↑↓→` — move floating window (±20px)
- `⌘+Tab` / `⌘+Shift+Tab` — focus next / prev

## Workspaces — macOS style
- `Ctrl+←` / `Ctrl+→` — workspace prev / next
- `Ctrl+↑` — window switcher (Mission Control)
- `⌘+1..0` — switch to workspace 1..10
- `⌘+Shift+1..0` — move window to workspace 1..10
- AZERTY top-row also bound via `bindcode`.

## Misc
- `Ctrl+⌥+L` — lockscreen
- `⌘+Shift+B` — wallpaper switch (yad + swww)
- `⌘+Shift+Y` — display mode picker
- `⌘+Shift+T` — swap waybar theme
- `⌘+Shift+I` — open this cheatsheet

## Screenshots
- `Print` — full screen
- `⌘+Print` — area
- `Ctrl+Print` — window
- `⌥+Print` — full, 5s delay
- `Shift+Print` — full, 10s delay

## Function keys
- `XF86MonBrightnessUp/Down` — brightness ± (brightnessctl)
- `XF86AudioRaiseVolume/LowerVolume/Mute/MicMute` — pamixer
- `XF86AudioNext/Prev/Play/Stop` — playerctl

## Mouse
- `⌘+Left-drag` — move window
- `⌘+Right-drag` — resize window
